# Homebrew tap

```bash
brew trust ryan-helou/tap
brew install --cask ryan-helou/tap/mac-memory-monitor
brew install --cask ryan-helou/tap/music-notch
```

| Cask | What it is |
|---|---|
| `mac-memory-monitor` | [Mac Memory Monitor](https://github.com/ryan-helou/MacMemoryMonitor): a menu bar app that shows why your Mac is lagging and helps free memory. |
| `music-notch` | [Music Notch](https://github.com/ryan-helou/MusicNotch): a Dynamic Island for the Mac notch with album art, music controls and full customization. |
